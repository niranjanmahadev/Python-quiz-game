# Python-quiz-game# 🧠 Python Quiz App

A simple interactive multiple-choice quiz application built using Python.

## ✨ Features

- ❓ Multiple-choice questions
- ✅ Automatic answer checking
- 🧮 Score calculation
- 🏆 Final result
- 💪 Feedback based on the score

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python quiz.py
```

5. Answer each question using **A, B, C, or D**.
